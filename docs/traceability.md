# Requirements traceability matrix

`Verified` means a repeatable repository check covers the implementation. `Implemented` means the code or configuration exists but its full acceptance exercise has not been completed. `Partial` identifies a known requirement gap. A repository test is not evidence that a live Google Cloud control works.

Still outstanding for academic acceptance: a live Google Cloud deployment, live Web Risk smoke test, backup restoration rehearsal, load test, manual accessibility assessment, user study, security review closure, and approval of the research data/model cards. Until those artefacts exist, this repository is an implementation candidate rather than a completed acceptance package.
